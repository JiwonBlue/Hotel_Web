# 🏨 호텔 에베레스트 (SpringBoot)
> **Spring Boot 기반의 직관적인 호텔 예약 및 정보 서비스**
> 프로젝트 기간: 2023.08.10 ~ 2023.08.25 (팀 프로젝트)

## 🛠 Tech Stack
- **Languages:** Java, JSP
- **Framework:** Spring Boot
- **Database:** Oracle DB
- **Collaboration:** GitHub

---

## 📱 담당 기능 및 성과
- **Project Lead:** 프로젝트 총괄 기획 및 DB 모델링
- **Backend:** 백엔드 전체 아키텍처 세팅 및 게시판 핵심 로직 구현
- **Frontend:** 게시판 및 호텔 소개 UI 개발, 카카오맵 API 연동
- **UX:** 사용자 편의를 고려한 인터페이스 기획

## 💡 깨달은 점
- **MVC 패턴:** Spring Boot를 사용해 MVC 패턴의 흐름을 명확히 이해하고 실제 웹 서비스에 적용해 보았습니다.
- **기획의 중요성:** 프로젝트 초반 기획이 탄탄하지 않으면 팀원 간의 소통 비용이 증가한다는 것을 깨닫고, 이후 더 꼼꼼한 기획 습관을 갖게 되었습니다.
- **기술 활용:** 카카오맵 API 등 외부 라이브러리를 연동하며 실무적인 문제 해결 능력을 키웠습니다.
